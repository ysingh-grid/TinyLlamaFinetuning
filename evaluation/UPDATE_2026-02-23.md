## Execution Steps

### A) Activate environment
```bash
source .venv/bin/activate
```

### B) Full FT retrain (safe sequence)
1. Sanity retrain
```bash
./run_full_retrain_safe.sh sanity
```

2. 20-prompt smoke gate
```bash
./run_full_smoke_eval.sh
```

3. Scale retrain
```bash
./run_full_retrain_safe.sh scale
```

4. One-epoch retrain (4000 iters)
```bash
./run_full_retrain_safe.sh epoch1
```

### C) Run full 6-model evaluation (500 prompts, 9 pairs)
```bash
SEED=42 ./evaluation/run_eval_6models.sh --judge-mode manual --progress-every 20
```

Output directory pattern:
- `evaluation/runs/YYYYMMDD_HHMMSS/`

### D) Manual judging format
Use:
- `evaluation/runs/<run_id>/pairing/judging_tasks.jsonl`

Create:
- `evaluation/runs/<run_id>/pairing/judgments_manual.jsonl`

Each line:
```json
{"item_id":"...","winner":"A|B|Tie"}
```
(`A/B/Tie` aliases are accepted and normalized.)

### E) Score and report
```bash
.venv/bin/python evaluation/score_judgments.py \
  --key evaluation/runs/<run_id>/pairing/judging_key.jsonl \
  --judgments evaluation/runs/<run_id>/pairing/judgments_manual.jsonl \
  --out-dir evaluation/runs/<run_id>/scoring \
  --seed 42
```

Generated metrics:
- win rate
- effective win rate (no ties)
- tie rate
- 95% bootstrap CI

Artifacts:
- `pair_metrics.json`
- `pair_metrics.csv`
- `model_rollup.json`
- `model_rollup.csv`
- `report.md`
