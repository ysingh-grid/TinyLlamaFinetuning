# TinyLlama Activation Vector Steering

Interactive demo showing how **activation steering** shifts a language model's
behaviour at inference time — without any weight update.

## What is Activation Steering?

Steering vectors are computed as the mean difference between hidden states
on "safe" vs "unsafe" prompts:

```
v̂_layer = unit( μ_safe − μ_unsafe )
```

At inference, this Space injects along **v̂** with **stability constraints** (see below), not raw `α·v̂` at every position.

## Model

| Component | Detail |
|-----------|--------|
| Base model | `TinyLlama/TinyLlama-1.1B-Chat-v1.0` |
| LoRA adapter | Rank 16, α = 32, layers 6–21 (q\_proj + v\_proj) |
| Steering layers | 8–20 (forward hooks on decoder blocks) |
| Vector source | BeaverTails safe/unsafe contrast (Task 2) |

## Steering Results (Task 2 Experiments)

| Layer | α = 0.5 | α = 1.0 | α = 1.5 |
|-------|---------|---------|---------|
| 8     | +0.06   | +0.12   | +0.18   |
| 10    | +0.10   | +0.19   | **+0.23** |
| 14    | +0.08   | +0.14   | +0.20   |
| 18    | +0.05   | +0.09   | +0.14   |

*Values show mean safety score gain vs. baseline (4.06 ± 1.53).*  
*Strongest effect: layer 10, α = 1.5 → mean safety 4.29 (+0.23).*

## Implementation Notes (this Space)

- **CPU-only** — no GPU-specific code; runs on Hugging Face free tier.
- **Hooks:** `ActivationSteerer.register_hooks()` — one forward hook per decoder layer **8–20**; inactive when `steerer.active = False`.
- **Injection site:** Only the **last sequence position** in each forward (next-token position). Broadcasting to all tokens was removed to avoid degenerate decoding.
- **Magnitude:** Update is **v̂-directional** with scale **∝ α · ‖h‖ / √L** (L = number of steered layers), not constant `α·v̂` in absolute units at every layer — see `steering.py` (`_REL_L2_FRAC`, `_STEER_N`).
- **Steered decoding:** `generate()` uses **repetition_penalty=1.22** and **no_repeat_ngram_size=4** for the steered pass only (baseline uses default settings).
- **UI:** `Steering` is **On/Off** (radio values `on`/`off`; off shows the same text as baseline in the steered column).
- **Context:** `steering_context(scale)` wraps one steered `generate()` call.
- **PEFT:** Adapter merged with `merge_and_unload()` before hooks attach.
- **Fallback:** if `peft` or adapter files are missing, the demo uses the base model only.

## Converting the MLX Adapter (reference)

The `adapters/r16/` directory was generated by `_convert_assets.py`:

```
MLX lora_a (in, rank) → PEFT lora_A.weight (rank, in)   [transpose]
MLX lora_b (rank, out) → PEFT lora_B.weight (out, rank)  [transpose]
```
